# Skrip Wakil Rombongan Meminang Naufal & Sarah

Projek ini mengandungi skrip penuh dan kad ucapan interaktif jurucakap pihak lelaki (Nabil Haikal) sempena Majlis Merisik & Meminang pada 7 November 2026 di Tim's Tea House Cafe, Taman Melawati.

## Susunan & Ciri Khas:
1. **Tema Warna Poster:** Gold, Mustard, Kuning, Wood Brown, dan Royal Cream.
2. **Susunan Bahagian 4 Dikemas Kini:**
   - **Bahagian 4A:** Perbincangan ketetapan mas kahwin/hantaran (3 dulang vs 5 dulang) dan penetapan tarikh nikah (13 Ogos 2027).
   - **Bahagian 4B:** Upacara penyerahan cincin dan hantaran selepas semua perkara dipersetujui.
3. **Ciri Interaktif:**
   - Input dinamik nama jurucakap pihak perempuan.
   - Pelaras saiz tulisan (A- / A+) untuk kemudahan membaca di telefon pintar.
   - Reka bentuk mesra cetakan (Print / Save as PDF).

## Cara Jalankan:
Buka sahaja fail `index.html` menggunakan mana-mana pelayar web (Chrome, Safari, Edge) atau 'drag & drop' terus ke Netlify / Vercel / GitHub Pages.
